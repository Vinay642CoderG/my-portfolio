# Vinay Bhagat — Portfolio

Personal portfolio for Vinay Bhagat, a Full-Stack Developer. It presents projects, technical skills, internship experience, education, services, and contact information.

Built with React, Vite, Tailwind CSS, Radix UI, Motion for React, and React Icons. The interface is responsive, animated, and supports light and dark themes.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

Portfolio content lives in `src/data`, while reusable components are in `src/components`.
